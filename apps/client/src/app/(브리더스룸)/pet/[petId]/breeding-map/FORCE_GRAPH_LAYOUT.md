# ForceGraph 노드 배치 규칙

d3-force 시뮬레이션 기반, 총 7개 힘(force) 조합.

## Forces

### 1. Link Force (`forceLink`) — 간선 거리
- 연결된 노드 간 **목표 거리 180px** 유지
- 부모-자식, 페어 간 간격을 일정하게 만듦

### 2. Charge Force (`forceManyBody`) — 반발력
- 강도 **-600** (음수 = 서로 밀어냄)
- 모든 노드가 서로 겹치지 않도록 퍼뜨림

### 3. Center Force (`forceCenter(0, 0)`)
- 전체 그래프의 중심이 **(0, 0)**에 오도록 유지

### 4. X Force (`forceX(0)`) — 수평 중심 복원
- 강도 **0.06** (약한 힘)
- 노드들이 X축 기준 너무 퍼지지 않게 중심으로 약하게 당김

### 5. Y Force (세대 기반) — 핵심 규칙
- `generation`이 있는 노드: **generation × 200px** 위치로 당김 (강도 **0.3**)
- `generation`이 없는 노드: Y=0으로 약하게 당김 (강도 **0.06**)
- G0(루트)는 Y=0, G1은 Y=200, G2는 Y=400... → **세대별로 위에서 아래로 정렬**

### 6. Collide Force (`forceCollide`) — 충돌 방지
- 각 노드의 **반지름 + 20px** 만큼 겹침 방지
- degree가 높은 노드(연결 많은)는 더 큰 반지름을 가짐

### 7. Pair Align Force (커스텀) — 페어 수평 정렬
- 강도 **0.6**
- `isPair` 엣지로 연결된 두 부모 노드의 **Y값을 평균으로 맞춤**
- 부/모가 같은 수평선 위에 나란히 위치하도록 보장

## 신규 노드 초기 위치

| 우선순위 | 조건 | 배치 |
|----------|------|------|
| 1 | 기존 시뮬레이션에 이미 있던 노드 | 같은 좌표 유지 |
| 2 | 기존 노드와 연결된 새 노드 | 이웃 위치에서 ±30px 랜덤 오프셋 |
| 3 | `initialNodePositionsRef`에 지정된 노드 | 지정 좌표 사용 (빠른 등록 등) |
| 4 | 이웃 없는 고아 노드 | 기존 트리 오른쪽 끝 +150px, Y는 기존 중심 근처 |

## 시뮬레이션 파라미터

| 파라미터 | 값 | 설명 |
|----------|-----|------|
| `alphaDecay` | 0.02 | 시뮬레이션이 천천히 식음 (더 안정적 배치) |
| 확장 시 alpha | 0.3 | 기존 노드 흔들림 최소화 |
| 최초 로드 alpha | 0.8 | 강하게 정렬 |

## 상수

| 상수 | 값 | 설명 |
|------|-----|------|
| `GENERATION_GAP` | 200 | 세대 간 Y축 간격 (px) |
| `GENERATION_Y_STRENGTH` | 0.3 | 세대 Y축 정렬 강도 |
| `PAIR_ALIGN_STRENGTH` | 0.6 | 페어 쌍 Y축 정렬 강도 |
| `PAIR_RADIUS_BOOST` | 8 | 센터펫 페어 노드 반지름 추가분 |
| `MIN_RADIUS` | (코드 참조) | 노드 최소 반지름 |
| `MAX_RADIUS` | (코드 참조) | 노드 최대 반지름 |
