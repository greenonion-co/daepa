# Server — Claude Code 지시사항

## 캐시 정합성 검증 (필수)
- 데이터를 생성·수정·삭제하는 코드를 작성하거나 변경할 때, 해당 데이터와 관련된 모든 캐시 키를 `cache-keys.ts` 및 `docs/caching.md`에서 확인할 것
- 변경되는 데이터가 캐시에 포함되어 있다면, 트랜잭션 커밋 이후 반드시 해당 캐시를 무효화할 것
- 직접 변경하는 엔티티뿐 아니라, 해당 데이터를 참조하는 다른 캐시(목록, 관계, 통계 등)도 함께 검토할 것
- 캐시 무효화 누락은 프로덕션에서 최대 TTL(30일)간 잘못된 데이터가 노출되는 치명적 문제를 유발함

## 캐시 문서 관리
- 서비스에 캐시를 적용하거나 제거할 때 반드시 `docs/caching.md`도 함께 업데이트할 것
