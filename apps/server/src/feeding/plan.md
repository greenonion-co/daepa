# 신규기능 - '피딩 기록'

## 내용
- 각 pet은 '피딩(먹이 급여) 기록'을 기록할 수 있다.
- feeding 테이블 추가
- 하나의 펫은 하루에 한 번 피딩 기록을 추가할 수 있다
- 피딩 기록을 추가할 때, api를 호출하는 유저가 pet의 Owner인지 검증한다
- 피딩 기록은 수정, 삭제 가능하다
- 우선 서버 api를 모두 구현한 뒤, client를 추후에 구현한다.
- 테이블 스키마, api 패턴 등은 기존 프로젝트의 컨벤션을 최대한 지킨다.
- 데이터 정합성, 쿼리 최적화, 성능 최적화를 중요하게 검증한다.
- 버그가 절대 없도록 한다.
